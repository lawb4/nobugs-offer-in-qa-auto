# Список требований к системе кинотеатра

- В кинотеатре есть несколько залов
- Каждый зал содержит ряды и места
- Покупатель может выбрать фильм
- Покупатель может выбрать зал
- Покупатель может выбрать сеанс
- Покупатель может выбрать конкретное место
- Можно добавлять фильмы
- Можно добавлять залы
- Можно бронировать места
- Можно проверять доступность места
- В будущем может появиться скидка на места у стены
- В будущем может появиться скидка на VIP-зону
